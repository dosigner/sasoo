# Sasoo v1.3.0 릴리스 사전 검증

사용자가 누적 변경의 push, build와 minor 릴리스를 요청해 v1.2.2에서 v1.3.0으로 준비했다. 원본 작업 폴더는 보존하고 별도 Git worktree에서 누적 제품 변경, 미추적 의존 모듈과 테스트, 관련 문서 및 필요한 고정 자료를 모았다.

## 포함 범위

읽기 가이드와 용어 사전, 선택 문맥 채팅과 분석 전 원문 문맥, 학문 분야 표시, 병렬 분석과 출력 완료 검사, 원문 기반 시각화 문맥 및 비용 미확인 처리, R1 보고서 조립과 R3 시각화 선택 규칙 분리를 포함한다. 미완료 manifest 원형은 기존 소스와 테스트를 보존하되 제품 실행 경로에 연결하지 않았다. 전체 리팩토링이나 실행 출처 및 비용 원장 설계가 완료된 것으로 설명하지 않는다.

시작 시 원본 파일 23,443개의 내용 해시 또는 심볼릭 링크 대상과 파일 모드, Git 상태를 기록했다. 기존 수정과 새 제품/테스트/문서 252개(약 46.84MiB)를 선별해 복사했고, 이후 버전과 릴리스 문서, 의존성 호환 수정을 추가했다. 약 3.2GiB 규모 미추적 자료의 대부분인 실험 산출물, 소스 복사본과 압축 파일, 도구 캐시 및 별도 마케팅 프로젝트는 로컬에 보존했다. 테스트가 직접 읽는 자료는 포함해 새 checkout에서도 검증할 수 있게 했다.

## 검증 환경과 결과

로컬 환경은 macOS ARM64, Python 3.12.13, Node 26.13.0, pnpm 10.32.1이다. Node 의존성 검사는 CI와 같은 pnpm 11.0.0을 사용했다. 정식 CI는 저장소 workflow의 Node 24와 Python 3.12를 사용한다.

| 검사 | 결과 |
|---|---|
| backend `pytest services api models tools` | 1,357 passed, 9 skipped, 236 subtests passed |
| 루트/Electron `pnpm test:unit` | 33 files, 291 tests passed |
| frontend `pnpm --dir=frontend test` | 46 files, 379 tests passed |
| frontend 타입 검사와 lint, Electron 컴파일 | 통과 |
| Node audit(moderate 이상) | root와 frontend 모두 통과 |
| Python `pip-audit==2.10.1` | 알려진 취약점 없음 |
| Python 설치 의존성 `pip check` | 충돌 없음 |
| macOS `pnpm build:mac:release` | Python 3.12로 패키징하고 ZIP 추출, manifest 크기와 해시 검사 통과 |
| 버전 동기화 | VERSION, root/frontend package, backend 문자열과 OpenAPI info.version이 1.3.0 |

백엔드 스킵 9건은 macOS Python 3.12에서 `os.waitid`가 없는 두 검사와 실제 사용자 DB/12편 라이브러리가 필요한 7개 검사다. 단위 검사와 실제 데이터/GUI 증거는 구분한다.

백엔드 테스트에는 별도 HOME, 앱 데이터, 임시 폴더와 Java 임시 경로를 사용하고 공급사 키를 전달하지 않았다. 실제 `.env`와 사용자 라이브러리를 복사하지 않았고, OS sandbox에서 외부 송신과 작업 폴더 밖 쓰기를 차단했다. Python socket 가드의 차단 2건은 기존 네트워크 가드 양성 대조다. 모든 자식 프로세스의 연결 시도를 전수 계측한 값은 아니다.

## 릴리스 준비 중 수정한 호환 문제

새로운 의존성 설치에서 PyMuPDF 2.1이 선택돼 줄바꿈 하이픈 인용의 검색 영역 검사가 실패했다. 최소 재현에서 저장한 텍스트는 같지만 검색 영역 수가 2.1에서는 0개, 1.28.2에서는 2개였다. PyMuPDF의 지원 범위를 `>=1.25.0,<2.0.0`으로 제한한 뒤 같은 기존 검사가 72 passed였고 전체 회귀도 통과했다. 기대값과 실제 사용자 파일은 바꾸지 않았다.

기존 lockfile의 취약점으로 필수 audit 검사가 실패해 기존 주 버전 범위의 패키지를 갱신했다. 수정 버전을 요구하는 하위 의존성에는 pnpm overrides를 적용했다. 특히 빌드 도구의 minimatch는 수정된 11.0.1로 지정하고 실제 macOS 빌드로 호환성을 확인했다. frontend audit에는 low 항목 1건이 집계되며 moderate 이상은 0건이다. 알려진 취약점이 전혀 없다고 표현하지 않는다.

릴리스 버전 변경으로 OpenAPI 고정 자료의 `info.version`만 1.2.2에서 1.3.0으로 바꿨다. API 구조나 다른 스냅샷 기대값은 바꾸지 않았다. 설치된 FastAPI 0.162.2와 Pydantic 2.14.3에서도 해당 계약 검사가 통과했다.

## 배포 단계에서 별도로 확인할 증거

이 문서는 로컬 사전 검증 기록이다. 정확한 릴리스 commit의 Windows Build Check, macOS/Windows Release workflow, GitHub 자산 다운로드 해시와 공개 상태는 GitHub의 해당 PR과 release 실행 기록에서 확인한다. 실제 Windows 설치, 공급사 응답과 청구, 과학적 정확성은 이 기록으로 검증한 것이 아니다.

원본 최초 해시, 선별/제외 목록과 실행 로그는 릴리스 전용 로컬 작업 폴더에 보존했다. 기존 dist와 사용자 데이터, 실제 키, 이전 유료 산출물에 정리 작업을 적용하지 않았다.
