## 남은 차단 사항

1. 기존 6편 과학 기준을 만족하는 제품 경로가 아직 없다. 실패 pilot은 제품에 넣지 않았다.
2. 질문 도우미와 하단 본문 겹침은 독립 시각 검토에서 확인했다. 수정은 아직 없다.
   세션 중 등록된 omo 스킬 경로가 사라져 필수 frontend 스킬을 읽지 못했고,
   등록 경로와 Codex/Orca/agents 경로를 검색해도 찾지 못했다. 기존 프로젝트 규칙으로
   계속할지 사용자에게 비동기 질문을 보냈으며 답변을 받기 전 해당 수정만 보류한다.
3. Windows 새 패키지/실기능, 최종 v1.0.1 양쪽 패키지, 릴리스 커밋 CI는 미실행이다.

버전은 1.0.0으로 유지했다. 커밋, push, 태그, 초안/공개 릴리스, 기존 자산 교체,
브랜치 삭제, SNS 게시는 수행하지 않았다. 기존 미커밋 UI 작업은 보존했다.

## 판정 원칙

과학적 정확성, 개발 앱 GUI, macOS 패키지, Windows 패키지는 각각 판정한다.
실행하지 않은 검사, 이전 소스의 증거, 생성 이미지는 현재 제품 검증으로 세지 않는다.
실패 기준과 기대값은 완화하지 않는다. 공개 전 자료는 개발 미리보기로 표시한다.
