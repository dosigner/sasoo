# 설정 폼과 워크벤치 6개 탭 디자인 적용 확인

날짜: 2026-09-24

## 적용 범위

- 설정 화면의 API 키 상태는 선택한 공급사의 **저장된 사용 가능 키**를 기준으로 표시한다. 읽을 수 없는 저장 키는 설정 완료로 보이지 않으며 공급사 카드도 선택할 수 없다.
- OpenAI와 Gemini 키를 한 묶음으로 정렬하고 입력 라벨, 키 표시 버튼 이름, 보관함 경로 선택 버튼 이름을 연결했다.
- 변경 저장바는 작업 내용 위에 떠 있는 조작층으로 표시한다. 주 저장 동작에 기존 `accent`와 어두운 모드 전용 전경 토큰을 사용한다.
- 워크벤치의 요약, 종합, 읽기 안내, 그림, 표, 레시피 제목과 상태/콘텐츠의 위계를 정렬했다. 읽기 면은 불투명한 `surface`, 그림과 표 카드는 테두리 중심 표면을 사용한다.
- 종합 탭의 시각화 자료가 없고 분석 실행 중도 아닐 때는 생성 중 스피너 대신 없는 상태를 표시한다. 생성, 실패, 부분 결과의 기존 상태와 원문 이동 동작은 유지한다.

## 검증 근거

| 항목 | 결과 |
| --- | --- |
| `pnpm tsc --noEmit`, `pnpm lint`, `pnpm test`, `pnpm build` | 통과. 프런트엔드 테스트 32개 파일, 314개 테스트 통과 |
| 개발 Electron 화면 | 1024×680, 1400×900에서 밝음/어두움, 설정과 6개 탭을 포함한 62장 캡처 |
| GUI 동작 검사 | 90/90 통과. 원문 PDF 이동과 요약 복귀, 부분/불명/오류 상태, 테마와 저장바 확인 |
| 추가 설정 상태 확인 | 읽을 수 없는 OpenAI 키는 재입력 안내, 공급사 선택 불가, 새 키 입력 시 저장바 표시. 어두운 모드 저장 버튼은 `accent`와 전용 어두운 전경 사용 |
| 저장 실패와 접근성 환경 | 격리 QA 서버의 변경 요청 거절 후 오류 문구와 저장바 유지. 투명도 축소 시 저장바 배경이 불투명하고 blur가 꺼지며, 움직임 축소 시 이동 대신 짧은 fade만 사용 |
| 모델 생성 요청 | 0회 |

최종 캡처와 기계 검사 원본은 [assets/forms-tabs-app-2026-09-24](assets/forms-tabs-app-2026-09-24/)의 `captures-r4/`, `checks-r4.json`, `source-hashes-r4.json`에 있다. 저장 실패와 접근성 환경의 추가 근거는 `extra-r6/`에 있다. 원문 PDF와 저장 분석 결과를 격리된 QA DB에 넣어 읽기 화면을 검사했다. 외부 모델 호출이나 실제 설정 저장은 실행하지 않았다.

이 결과는 `packaged=false`인 **개발 Electron GUI 검증**이다. 배포용 패키지, Windows, 논문 내용의 과학적 정확성은 여기서 검증하지 않았다. 종합 결과가 없는 QA 논문에서 `/api/analysis/*/synthesis`의 GET 404가 8회 기록됐으며, 생성 요청이나 페이지 JavaScript 오류는 없었다.

비교 HTML은 원칙을 설명하는 시안이다. 실제 앱은 기존 그림 썸네일, 표 캡션, PDF 이동 등 상세 기능을 유지하므로 시안과 픽셀 단위로 같지 않다.
