# Sasoo 1.0.1 실논문 대조용 원문과 기준 답변

작성일: 2026-09-22. 상태: **원문 준비 기록**. 이후 실제 모델 검증 결과는 [검증 기록](2026-09-22-v1.0.1-summary-reading.md)을 따른다.

이 문서는 Task 6 Step 2의 입력 준비 기록이다. 아래 답변은 원문을 읽어 작성한 대조 기준이며 Sasoo가 생성한 분석 결과가 아니다. 준비 단계에서는 유료 모델 API를 호출하지 않았다. 이후 검증 실행과 이 원문 준비는 별개이며 실험 재현, 로봇 실행, 사용자 학습 효과 측정은 수행하지 않았다. 실제 모델의 오류 수, tokens, 비용, 생성 시간은 이 기록으로 통과 처리할 수 없다.

## 입력과 재현 방법

- 확정한 여섯 PDF와 원문 텍스트는 `/tmp/sasoo-v101-papers/`에 있다. 이 임시 경로는 시스템 정리 시 사라질 수 있다. 원문 URL, 정확한 버전, SHA-256, 파일 크기, 페이지 수, 텍스트 경로와 해시는 [manifest.json](assets/v1.0.1-summary-reading/papers/manifest.json)에 기록했다.
- `.input.txt`는 `pdftotext` 기본 읽기 순서, `.txt`는 `pdftotext -layout` 결과다. 텍스트 추출만으로 수식과 도표가 보존된다고 가정하지 않는다. 원본 PDF를 최종 근거로 사용한다.
- 이전/개선 지시문 비교 후보는 `bio1`, `robotics1`이다. 각 쌍에 같은 PDF 또는 같은 추출 텍스트, 같은 모델 설정을 사용하고 입력 해시를 기록한다. 이 기준 답변과 manifest, 검사 화면은 모델 입력에 섞지 않는다.
- 원문의 절, 그림, 표가 생성 결과의 `source_refs` 기준이다. 이 문서의 PDF 페이지는 사람이 검사한 위치이며, 새 필드의 페이지 링크로 복사하지 않는다.
- `reported`는 원문 진술, `inferred`는 그 진술에서 도출한 판단, `not_reported`는 제공 범위에서 확인하지 못한 정보다. 적용 전 확인 제안은 저자가 검증한 결과나 적용 가능 판정이 아니다.

## theory: Bell의 국소 숨은 변수 모형

| 기준 질문 | 기준 답변과 짧은 뒷받침 | 정확한 원문 위치 |
|---|---|---|
| 무엇이 문제인가? | 국소적인 숨은 변수로 양자역학의 singlet 상관을 재현할 수 있는가를 묻는다. | I, II |
| 왜 결론이 나오는가? | 결과 A/B를 ±1로 놓고, 각 결과가 먼 측정 설정에 의존하지 않는다고 가정한다. 정규화된 숨은 변수 분포로 평균내면 상관함수가 제약된다. | II, 식 (1)/(2), IV |
| 결과와 성립 조건은? | 식 (15)의 부등식은 국소 모형의 제약이며, singlet의 양자 상관 `−a·b`와 양립하지 않는다. a/b/c는 측정 방향 단위벡터이고 상관은 무차원이다. | 식 (3)/(15), IV |
| 주요 한계는? | 이것은 지정한 가정들의 양립 불가능성에 관한 증명이다. 모든 숨은 변수 모형을 배제하거나 이 논문 자체가 실험으로 국소성을 반증했다고 쓰면 틀린다. | III, V, VI |
| 적용 전에 무엇을 확인하나? | `reported`: 국소성, 측정 결과 범위, singlet 상관을 전제한다. 확인 제안: 적용할 논증이 같은 가정을 쓰는지 확인한다. 실험 시약/장비나 as-is/to-be를 요구하지 않는다. | II, IV, V |
| 무엇을 확인하지 못했나? | 이 논문은 검출 효율, 장치 보정값, 실험 시행 수를 보고하는 실험 연구가 아니다. 해당 항목은 결함이나 임의 기본값이 아니라 비적용이다. | 제공 범위: I~VI 전체 |

검사 화면: [가정과 식 (1)~(3)](assets/v1.0.1-summary-reading/papers/theory-formulation.png), [식 (15)](assets/v1.0.1-summary-reading/papers/theory-inequality.png). 원본 OCR 텍스트에는 식이 빠져 있으므로 **텍스트만으로 수식 이해를 검증했다고 보고하면 안 된다**.

독립 QA 검산: `a`와 `c`를 직교하게, `b=(a+c)/√2`로 놓고 식 (3)을 식 (15)에 넣으면 왼쪽은 `1−1/√2≈0.292893`, 오른쪽은 `1/√2≈0.707107`이다. 요구되는 왼쪽 ≥ 오른쪽이 성립하지 않는다. 이는 이 기록의 수학적 검산이며 논문의 실험 측정값이 아니다.

## 수집 및 검사 기록

1. 관련 로컬 PDF 목록을 먼저 확인했으나 이번 여섯 유형과 정확히 맞는 세트는 없었다. 공개 출판사 PDF 또는 버전이 고정된 arXiv PDF를 다운로드했다.
2. 최초 후보 Jinek 2012의 Science/PMC PDF 경로는 403 또는 challenge HTML을 반환했다. 정상 PDF라고 보고하지 않았다. 공식 eLife PDF가 확보된 Jinek 2013으로 변경했다. CERN Bell 경로 역시 challenge HTML이어서 공식 APS PDF를 사용했다. 최종 세트에는 모두 `%PDF-` 헤더와 `pdfinfo` 페이지 수가 확인됐다.
3. Firecrawl로 PMC/eLife/arXiv의 링크와 제공 자료 범위를 확인했다. 설치된 CLI에는 `research` 명령과 관련 스킬 파일이 없어 해당 기능을 사용하지 않았다. 바이너리 PDF는 공식 URL에서 `curl`로 확보했다. 모델 생성 기반 추출은 사용하지 않았다.
4. PDF → 텍스트 추출 뒤 위의 7개 원문 검사 화면을 렌더하고 직접 확인했다. [source-checks.txt](assets/v1.0.1-summary-reading/papers/source-checks.txt)는 파일 검증 결과이며, 앱 GUI 검증 결과가 아니다.
5. DESeq2와 Diffusion Policy 등에서는 폰트에 기인한 제어문자가 추출됐다. 원문 PDF와 텍스트를 수정하지 않았고 manifest에 개수를 기록했다. Bell의 표시 수식 누락도 입력 한계로 남겼다.

해시는 다음 명령으로 재검증한다. 이 명령은 모델을 호출하지 않는다.

```sh
shasum -a 256 -c docs/validation/assets/v1.0.1-summary-reading/papers/SHA256SUMS
```

실제 모델 검증 단계에서 남은 일: 여섯 생성 결과를 위 여섯 질문과 대조하고, 생성된 절/그림/표가 실제 위치로 연결되는지 앱에서 확인한다. `bio1`과 `robotics1`의 이전/개선 지시문 비교에는 같은 입력 해시와 모델 설정, 입력/출력 tokens, 비용, 시간을 별도로 기록한다. 고정 fixture가 통과하거나 이 원문 준비가 완료됐다는 이유로 그 결과를 대신하지 않는다.
