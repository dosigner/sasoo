# 워크벤치 칩 통일 + 헤더 다이어트 — 설계 (우측 패널 재정비 후속)

날짜: 2026-08-05
상태: 사용자 승인(제안 1·2·4 선택. 3=raw enum 한국어화는 범위 밖, 5=세그먼트 토글은 유지).
전편: `2026-08-04-workbench-right-panel-design.md` — 토큰·문체·다이얼 규칙을 그대로 상속.

## 배경

우측 패널 본문 재정비 후, 남은 태그류가 구세대 문법 3종(보더형 회색 칩·배경형 칩·mono
대문자 필)으로 혼재해 새 스타일과 충돌한다. 실물 확인 지점: 워크벤치 헤더 칩 4개
(`ai_ml`/`뉴럴 에이전트 ▾`/`분석 완료`/`심층 분석 완료`), Phase 섹션 "✓ 완료" 배경 뱃지,
"추출한 그림 14" 숫자 뱃지, "질문 도우미 준비됨" 칩.

## 규칙

### 1. 칩 어휘 단일화
- 워크벤치 화면(헤더+우측 패널+질문 도우미)의 칩은 한 가지 스타일만: **보더 없는 저채도
  틴트 칩** — 시맨틱 색 8~12% 배경(`--accent`/`--success`/`--warning` 기반), radius pill,
  12px·500, 텍스트는 해당 시맨틱 색의 진한 톤.
- 공용 유틸(클래스 또는 기존 `ui/Badge` 개편 중 코드베이스에 맞는 쪽)로 정의하고, 워크벤치
  표면의 기존 `status-pill`·보더 칩을 이 스타일로 이관한다. 워크벤치 밖 화면은 건드리지
  않는다.
- 상태성 정보만 칩을 쓴다. 정보성 숫자·완료 표시는 칩에서 해제(§3).

### 2. 헤더 다이어트 (WorkbenchHeader)
- 상태 칩 2개(`분석 완료`, `심층 분석 완료`) → **1개로 축약**: 가장 진행된 상태
  (`trustStateLabel || runStateLabel`, 우측 패널 상태부와 같은 우선순위) 하나만 §1 칩으로.
- `ai_ml` 도메인 칩 → 전편에서 만든 `DOMAIN_LABELS` 매핑 재사용해 한국어 표기.
- 에이전트 선택(`● 뉴럴 에이전트 ▾`)은 칩 모양을 버리고 조용한 셀렉트 스타일(텍스트+
  셰브론, hover 시 배경)로. 기능·선택 로직 무수정.

### 3. 정보성 숫자·완료 표시의 칩 해제
- "추출한 그림 `14`" 뱃지 → 제목 옆 muted 숫자 텍스트(`추출한 그림 14`, 12px 400).
- Phase 섹션 "✓ 완료" 배경 뱃지 → 배경 없는 체크 아이콘(`--success`) + muted 텍스트.
- "질문 도우미 `준비됨`" 칩 → §1 틴트 칩 1개로 통일(또는 상태 텍스트로 강등 — 구현 시
  주변 문법에 맞는 쪽, 리포트에 기록).

## 범위 밖
- raw enum 값 한국어화(`AUTHOR_YEAR` 등 citation/deep_dive 필 값) — 사용자 선택으로 제외.
- 그리드/커버플로우 세그먼트 토글(현행 유지), 워크벤치 밖 화면, 기능·API.

## 검증
- 기존 테스트 통과 + 실행 스크린샷(헤더 포함 전폭, 라이트·다크)으로 목업 문법 대조.
- 전편 Global Constraints(굵기 400/500/650, 해요체, em-dash·화살표 금지, transition 명시,
  reduced-motion) 전부 상속.
