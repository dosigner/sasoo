# Sasoo 리브랜딩 로고 디자인 스펙

- 날짜: 2026-07-12
- 상태: 사용자 승인 대기
- 범위: 로고 마크·앱 아이콘·파비콘·히어로 이미지. **앱 이름("Sasoo")과 디자인 시스템 v2 컬러 토큰은 변경하지 않는다.**
- 선행 문서: `docs/superpowers/specs/2026-07-12-design-system-v2-design.md` (디자인 시스템 v2)

## 1. 컨셉

한글 자음 **ㅅ 두 개를 겹친 모노그램**. 앞의 큰 ㅅ(퍼플)은 사수, 뒤의 작은 ㅅ(그레이)은 부사수(사용자)로, "AI 사수가 연구자 곁에 서 있다"는 앱 네이밍의 어원을 그대로 시각화한다. 부수 은유로 산봉우리(연구의 등반)로도 읽힌다.

브라우저 비주얼 세션에서 다음 순서로 확정했다:
조형 방식 A(라인 듀오) → 접합부 V1(크로스) → 획 스타일 풀 라운드 · 두께 28 → 개선안 A(기준안 유지) → 타일 T3(소프트 그라데이션) → 글래스 엣지 G2(리퀴드 글라스), G3(프로스티드)는 히어로 전용 파생.

## 2. 마스터 마크 (기하 정의)

단일 원본 SVG에서 모든 자산을 파생한다. 좌표계는 `viewBox="0 0 240 170"`.

| 요소 | 값 |
|---|---|
| 앞 ㅅ (사수) | `M38 146 L96 28 L154 146` |
| 뒤 ㅅ (부사수) | `M122 146 L166 57 L210 146` |
| 획 두께 | 28 (두 획 동일) |
| 캡/조인 | `stroke-linecap="round"` `stroke-linejoin="round"` (풀 라운드) |
| 꼭짓점 각도 | 두 글리프 동일 (약 52°) |
| 베이스라인 | 네 다리 끝 모두 y=146 정렬 |
| 크기 위계 | 뒤 ㅅ 높이 = 앞 ㅅ의 약 0.75배 |
| 접합부 | V1 크로스 — 뒤 ㅅ의 왼다리가 앞 ㅅ의 오른다리 **뒤로** 지나감 (그리기 순서: 뒤 ㅅ 먼저) |

### 마크 단독 배색

| 컨텍스트 | 앞 ㅅ | 뒤 ㅅ |
|---|---|---|
| 라이트 배경 | `#683DCC` (accent) | `#A1A1AA` |
| 다크 배경 | `#7C5AE8` (accent-dark) | `#52525B` |
| 타일 위 (화이트 녹아웃) | `#FFFFFF` 100% | `#FFFFFF` 55% |

v2 토큰 13종 밖의 신규 컬러는 타일 그라데이션(3장)과 히어로 파생(4장)에만 국한하며, UI 컴포넌트에는 유입하지 않는다.

## 3. 앱 아이콘 — G2 리퀴드 글라스 (본안)

타일 좌표계는 `viewBox="0 0 140 140"`. 레이어는 아래에서 위 순서.

1. **베이스 타일**: `rect 140×140 rx=30`, 수직 그라데이션 `#8B67E9`(상) → `#5B2FC7`(하)
2. **스펙큘러 시트**: `path M0 0 H140 V50 Q70 76 0 50 Z`, 수직 그라데이션 white 0.30 → 0.02, 타일에 클리핑
3. **하단 이너 섀도**: `ellipse cx=70 cy=152 rx=86 ry=26`, `rgba(30,12,70,0.35)`, Gaussian blur σ=7, 타일에 클리핑
4. **림 하이라이트**: `rect` inset 1.25, `rx=28.75`, stroke 2.5, 수직 그라데이션 white 0.90(상) → 0.25(35%) → 0.07(하)
5. **글리프 깊이 그림자**: 글리프 복제를 y+1.5 오프셋, `#2A1360` opacity 0.30
6. **글리프**: 마스터 마크를 `translate(12,30) scale(0.47)`, 타일 배색(화이트 100%/55%), stroke 30 (마스터의 28에서 증량 — 축소·화이트 반전 시의 시각 보정이며 의도된 값)

### 3.1 크기별 파생 규칙 (글래스는 크기에 따라 벗겨낸다)

| 크기 | 구성 |
|---|---|
| 64px 이상 (Dock, 스토어) | 풀 글래스 — 레이어 1~6 전부 |
| 32~63px (탭, 목록) | 레이어 2·3·5 제거, 림(stroke 4)+그라데이션+글리프(stroke 34)만 |
| 31px 이하 (16px 파비콘) | 플랫 — 그라데이션 타일(`rx=34`)+글리프만, 글리프 stroke 40으로 증량 |

플랫(16px) 파생판의 뒤 ㅅ은 white 55% 대신 **white 60%**를 쓴다 — 초소형 크기에서의 가독성 보정이며, 64px+·32px 파생판은 전역 규칙(55%)을 따른다.

## 4. 히어로 파생 — G3 프로스티드 (랜딩·README 전용)

배경 이미지가 있어야 성립하는 재질이므로 **앱 아이콘·파비콘에는 쓰지 않는다.**

- 판: `rx=24` 사각형, `rgba(255,255,255,0.40)` + 배경 블러 σ=9 (SVG는 배경 복제-클리핑, 웹은 `backdrop-filter: blur(9px)`)
- 림: stroke 2, 수직 그라데이션 white 0.95 → 0.35(45%) → 0.15
- 마크: 원색 사용 — 앞 ㅅ `#683DCC`, 뒤 ㅅ은 라벤더 그레이 `#8F89A3` (프로스티드 판 위에서 순수 뉴트럴 `#A1A1AA`가 탁해 보이는 문제의 보정; 히어로 한정 예외 배색)

## 5. 워드마크 락업

- 서체: Pretendard SemiBold(600), 표기 "Sasoo", letter-spacing -0.01em
- 타이틀바 락업: 아이콘(16px 플랫판) + 8px 간격(`gap-2`) + 워드마크(SemiBold, -0.01em)
- 사이드바 락업: 아이콘(32px 림판) + 디자인 시스템 v2 사이드바 규격(`.app-sidebar-brand`: gap-2.5, tracking-tight)을 따른다 — v2가 사이드바 타이포그래피의 상위 규범
- 별도 커스텀 레터링은 하지 않는다 (앱 본문 서체와 동일 계열 유지)

## 6. 교체 대상 자산 (구현 단계)

| 생성 자산 | 교체/신설 위치 |
|---|---|
| `logo-mark.svg` (마크 단독, 라이트/다크 2종) | `sasoo/frontend/src/assets/` 신설 |
| `app-icon.svg` (G2 마스터) + 1024/512 PNG | `sasoo/build/icon.png` 교체 |
| 타이틀바·사이드바 로고 | `Titlebar.tsx`, `AppSidebar.tsx`의 `logo.png` 참조 교체 (32px 파생판) |
| `favicon.svg` + 16/32 ICO/PNG | `sasoo/frontend/public/` 신설, `index.html`에 링크 (현재 파비콘 부재) |
| README 히어로 (G3, PNG 또는 SVG) | `sasoo/docs/assets/logo.png` 교체 |

기존 `logo.png`(그라데이션 프리즘 리본)는 전면 대체한다. `ExperimentPlanTab.tsx`의 "사수의 한마디" 등 카피는 변경 없음.

## 7. 성공 기준

- 16px 파비콘에서 두 ㅅ이 뭉개지지 않고 판독됨 (플랫 파생판 기준)
- 라이트/다크 배경 각각에서 마크 단독 배색이 정의돼 있고 임의 변형이 불필요함
- 모든 자산이 마스터 SVG 하나에서 수치 규칙으로 파생됨 (손보정 금지)
- 앱 아이콘이 macOS Dock에서 시스템 아이콘들과 이질감 없이 앉음

## 8. 범위 외 (이번 리브랜딩에서 하지 않는 것)
