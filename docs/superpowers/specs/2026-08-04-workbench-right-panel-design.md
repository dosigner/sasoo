# 워크벤치 우측 패널 재정비 (Quiet Minimal) — 설계

날짜: 2026-08-04
상태: 사용자 승인 완료 (브레인스토밍 + 비주얼 컴패니언에서 A안 선택, 폴리시 리뷰 반영 v2 승인)
목업: `.superpowers/brainstorm/20735-1785848734/content/final-design-v2.html` (구현 기준)

## 배경 (진단)

demo.gif 실물 프레임 기준, 우측 패널이 옛날스러운 원인 6가지:

1. 뱃지·필 남발 + 내부 파이프라인 용어 노출(`resolver-v1`, `heuristic`, `gemini-subfigure`)
2. Phase 1~5 테두리 박스 + 점선 화살표 스테퍼
3. 보더 박스 중첩(상태바·섹션·카드 안 카드)
4. 분석 상태바의 칩 나열(위계 없음)
5. 요약 탭 key-value 평문(`분야: optics`)
6. 카드마다 반복되는 아웃라인 버튼(`→ PDF 페이지로 이동`)

홈(커버플로우·ARC 카드)은 이미 현대적이라 세대 차이가 도드라짐.

## 방향

**Redesign-preserve · Quiet Minimal(Linear류).** 새 스타일 발명 없이 기존 토큰 시스템만 사용:
Pretendard Variable, `--accent`(104 61 204 보라), `--bg`/`--surface`/`--border`/`--fg` 3단
전경색, `--radius-control` 6 / `--radius-surface` 12 / `--radius-pill`, `--transition-speed`
150ms, `--ease-out-strong`. 다이얼: VARIANCE 4 / MOTION 3 / DENSITY 5.

레이아웃 골격(좌 PDF·우 패널 분할, 탭 구조), 기능, API, 데이터 계약은 무수정. 스타일과
정보 표현만 바꾼다.

## 컴포넌트별 규칙

### 1. 상태부
- 칩 나열 → 상태 한 줄(명사구, 예: "심층 분석 완료", 650) + 우측에 단계 경로·카운트
  (11px muted, `tabular-nums`).
- 그 아래 3px 진행 레일(트랙 `--border`, 채움 `--accent`, radius pill).
- Phase 1~5 박스·점선 화살표 전부 삭제. 단계명은 "Phase N"이 아니라 실제 이름
  (스크리닝 → 인용 → 시각 → 레시피 → 심층). 진행 중에는 현재 단계만 강조.

### 2. 탭
- 라벨 한국어 통일: **요약 · 그림 · 표 · 레시피 · 실험 계획**
  (앱의 기존 문구가 이미 "그림"을 사용 — 멘탈 모델 일치).
- 활성 = `--fg` 650 + 2px 액센트 언더라인. 비활성 = muted 500. 아이콘 제거.
- 전환은 150ms opacity/색만(기존 토큰). 탭 전환마다 입장 애니메이션 재생 금지.

### 3. 요약 탭 메타
- key-value 평문 → 4열 메타 그리드: 라벨(10px 500 muted) 위 + 값(13px 650) 아래.
- EXPERIMENTAL·복잡도 HIGH 류 컬러 뱃지 삭제, 값은 한국어("실험 논문", "높음").
- 수치(관련도 % 등)는 `tabular-nums`, 관련도만 액센트색 허용.

### 4. 카드 (그림·표 공통)
- **썸네일 풀블리드**: 이미지가 카드 상단을 꽉 채우고 위 모서리 radius(12)를 카드와 공유
  → concentric radius 문제 원천 해소. 텍스트 영역만 패딩.
- **깊이 = 그림자, 상태 = 보더**: 기본 카드는 보더 없이
  `0 1px 2px rgba(0,0,0,.04), 0 2px 8px rgba(0,0,0,.04)` 2겹. 선택/포커스만 액센트 보더.
  다크 모드에선 그림자 대신 surface 톤 차이 + 상태 보더 유지.
- 캡션 한 줄: "Figure 11" (650) + "서브피겨 4 · p.7" (11px muted, tabular-nums).
- **신뢰도 = 시맨틱 색점**(7px, `--success` ≥ 임계 / `--warning` 미만, 비인터랙티브).
  상세는 카드 hover 툴팁: "신뢰도 53%, 검토를 권해요".
- 카드 전체가 클릭 영역(PDF 해당 페이지로 이동). 아웃라인 버튼 삭제.
  press 시 `scale(0.96)` + `transition-property` 명시(`all` 금지).
- **내부 용어 완전 제거**: `resolver-v1`·`heuristic`·`gemini-subfigure`·`Composite` 류는
  기본 UI에서 렌더하지 않는다. 개발자 모드 토글(설정)이 켜진 경우에만 노출.

### 5. UX writing
- 해요체 통일(기존 앱 어조). 상태는 명사구, 진행형은 "~하고 있어요".
- em-dash(—) 사용 금지. 구분은 가운뎃점 1개 이하 또는 쉼표.
- 버튼·링크는 동사 우선("PDF에서 보기"). 화살표 문자(→)를 라벨에 넣지 않는다.

### 6. 모션·접근성
- hover/전환 150ms 기존 토큰, 새 keyframe 애니메이션 추가 금지(MOTION 3).
- `prefers-reduced-motion` 존중(전환 즉시 완료).
- 색점은 색만으로 정보 전달 금지 → 툴팁 텍스트 병행. 대비 WCAG AA.

## 굵기·radius·색 잠금 (폴리시 리뷰 결론)

- 굵기 3단계 잠금: **400(본문) / 500(라벨·비활성 탭) / 650(값·제목·활성 탭)**. 700 미사용.
- radius: 기존 토큰 6/12/pill 외 새 값 금지.
- 색: 액센트 보라 1색 + 시맨틱 success/warning 색점만. 새 색 추가 금지.
