## Sasoo 편집 제안

이미지는 한 장으로 고정할 필요가 없다. 서로 다른 질문에 답하는 시각 자료 다섯 개를 후보로 잡고, 중복되는 것은 합치는 편이 적절하다.

| 위치 | 시각 자료 | 답할 질문 | 제작 방식 |
|---|---|---|---|
| 짧은 제품 소개 | 논문 중심의 얇은 브랜드 배너 | 어떤 연구 도구인가? | `imagegen`, 논문 지면과 근거 연결을 표현 |
| 다운로드 링크 다음 | PDF와 해설을 나란히 보여주는 워크벤치 | 실제로 어떻게 생겼나? | 실제 앱 캡처 |
| 논문 이해 기능 설명 | 질문과 요약을 읽는 확대 화면 | 논문의 흐름을 어떻게 이해하나? | 실제 앱 캡처 |
| 근거 확인 기능 설명 | Figure/Table 원문으로 돌아가는 짧은 데모 | 설명의 근거를 어떻게 확인하나? | 실제 앱 녹화 |
| 실험 조건 정리 기능 설명 | 파라미터와 출처를 읽을 수 있는 레시피 화면 | 읽은 내용을 다음 작업에 어떻게 활용하나? | 실제 앱 캡처 |

다섯 개 모두를 AI로 생성하지 않는다. 기능의 증거는 앱 캡처와 실제 동작으로 보여주고, 생성 그림은 논문 중심의 제품 인상을 표현하는 역할에 쓴다. 별도의 읽기 여정 그림은 위 화면 설명과 중복되므로 추가하지 않는다. 시작하기는 짧은 세 단계 텍스트로 안내한다.

## 논문 느낌을 강화할 생성 이미지 조건

- 펼친 책, 책등, 두꺼운 제본 대신 얇은 독립 논문 페이지와 평평한 PDF 지면을 중심에 둔다.
- 제목 영역, 저자 줄, 초록 블록, 두 단 본문, Figure와 Table 영역처럼 논문을 식별하게 하는 지면 구조를 쓴다.
- 보라색 강조 구절과 해설 조각을 연결하되, 실존 논문의 결과나 수치처럼 보이는 정보를 창작하지 않는다.
- 기존 앱의 화면으로 오해할 가상 버튼, 탐색 막대, 성공 상태는 넣지 않는다.
- 이미지 속 문장을 최소화하고 제목과 설명은 README의 실제 텍스트로 둔다. 한영 문서는 같은 그림과 같은 기능 범위를 공유한다.

## 적용 전 확인

캡처는 README가 설명하는 버전과 맞추고 개인정보와 키가 보이지 않는지 확인한다. 작은 화면에서도 설명에 필요한 부분이 읽히는지, 밝은 배경과 어두운 배경에서 외곽이 구분되는지, 저장소에서 이미지 경로가 실제로 열리는지 확인한다. 생성 콘셉트를 제품 동작이나 과학적 정확도의 증거로 사용하지 않는다.
