# 4. 논문사수 Home 적용안 — 3옵션

> 공통 전제: 기존 컴포넌트(UploadPanel, RecentPaperRow, getCostSummary) 보존·확장. 색·라벨 관행(text-2xs uppercase, accent 단일 포인트)은 이미 2026 기조와 일치하므로 유지.

---

## 옵션 1 (권장) — "업로드 히어로 + 스탯 행 + 최근 논문 리스트"

Dropbox Dash/Humata형 병존 골격(src_018, src_011) + Stripe 스탯 문법(src_004) + shadcn 스택(src_021). 신규 백엔드 없이 위계 재배치만으로 구현 가능.

```
┌─────────────────────────────────────────────────┐
│ 7월 13일 일요일                                    │
│ 안녕하세요, 동주님            ← 인사 유지(작게)     │
├─────────────────────────────────────────────────┤
│ ╔═══════════════════════════════════════════╗   │
│ ║      ⬆  논문 PDF를 끌어다 놓으세요           ║   │
│ ║   또는 클릭해서 선택 · 붙여넣기(⌘V)          ║   │  ← 히어로 (화면폭 전체,
│ ║   .pdf · 최대 NN MB                        ║   │     점선보더, 드래그오버 반응)
│ ╚═══════════════════════════════════════════╝   │
├──────────────────────────┬──────────────────────┤
│ 최근 논문                  │ 이번 달 비용           │
│ ● 논문A  [분석완료] 3시간 전 │ $12.34               │  ← 좌: 행 리스트(2/3폭)
│ ● 논문B  [진행중 64%] 어제  │ ▁▃▂▅ 지난달 대비 −12% │     우: 스탯 타일(1/3폭)
│ ● 논문C  [미분석]   7/10   │ 분석 논문 8편          │
│ 전체 보기 →                │ 설정에서 상세 →        │
└──────────────────────────┴──────────────────────┘
```

- **히어로 드롭존**: 점선 보더, 드래그오버 시 보더 색+배경 톤 변화, 파일별 독립 진행 행(src_044, src_045, src_046). 포맷·용량 마이크로카피는 ChatPDF/Adobe 방식(src_009, src_020).
- **업로드 직후**: 진행 단계(업로드→파싱→분석) 표시 후 워크벤치로 즉시 전이 — SciSpace형(src_010). 완료 시 "기여점 요약 보기" 등 도메인 칩.
- **최근 논문 행**: 상태 배지(분석완료/진행중/실패)를 1급 정보로 — Vercel 카드의 상태 배지 원칙(src_002). `analyzed_at` 상대시간 표기 유지.
- **비용 타일**: 라벨(TEXT-2XS) → tabular-nums 큰 숫자 → 보조 라인(월 스파크 또는 "논문 N편 분석"). 일별 바차트는 넣지 않는다(§3.3-3).
- **빈 상태**: 리스트 자리에 "첫 논문을 업로드해보세요" + 드롭존 포커스 버튼(src_043); 비용은 $0.00 + 보조문구.
- **모션**: 히어로→리스트→타일 순 스태거 40~80ms, 전체 700ms 이내(src_050, src_051).

**장점**: 리스크 최소, 기존 데이터로 충분, 효과 즉시. **단점**: "발견형"의 새로움은 없음.

## 옵션 2 — "발견형 하이브리드" (2026 프런티어형)

2026년 프런티어는 AI가 먼저 주목할 것을 제시하는 발견형 대시보드(Attio, Hex, Cursor)로 이동 중이다(src_037, src_039). 인사말 자리를 "AI가 먼저 말하는 한 줄"로 승격.

```
┌─────────────────────────────────────────────────┐
│ 안녕하세요, 동주님.                                 │
│ 「논문B」 분석이 곧 끝납니다 · 「논문C」는 아직        │
│ 분석 전이에요 → [이어서 하기]     ← AI 요약 라인     │
├─────────────────────────────────────────────────┤
│ (이하 옵션 1과 동일: 히어로 드롭존 + 리스트/타일)      │
└─────────────────────────────────────────────────┘
```

- 요약 라인 재료(이미 있음): 진행중 분석, 미분석 논문 수, 마지막 작업 논문. 장기적으로 "지난 분석에서 미해결 코멘트 N개" 같은 신호 추가.
- **장점**: 가장 "요즘"스러움, 재방문 가치 상승. **단점**: 요약 신호 선정 로직 필요 — 신호가 빈약하면 오히려 공허.

## 옵션 3 — "프롬프트형 홈" (SciSpace형, 장기 옵션)

SciSpace/Elicit처럼 홈을 입력창 중심으로(src_010, src_015): "논문을 끌어놓거나, 무엇을 도와줄지 입력하세요" — 업로드·질문·검색이 한 입력창에 통합(Gamma형 동급 진입, src_013).

- **장점**: 기능 확장(질문, 라이브러리 검색, 첨삭 지시)의 그릇이 됨. **단점**: 현재 IA(업로드→워크벤치 단선)와 거리, 채팅 백엔드 전제 — 지금은 시기상조. 옵션 1→2를 거친 뒤의 종착점 후보.

---

## 공통 체크리스트 (구현 시)

1. 업로드 버튼을 전역(사이드바/헤더)에도 고정 — Elicit 원칙(src_015). AppSidebar에 "+ 새 논문" 상시 노출.
2. 벤토는 히어로+타일 2~4개까지만, 리스트는 리스트로(src_038).
3. 보더 최소화 — 카드 구분은 배경 레이어·여백으로, 다크모드 elevation 스텝 별도 정의(src_037, src_047).
4. 스탯 숫자 tabular-nums(이미 비용 히어로에 적용된 관행 유지), 라벨은 기존 text-2xs uppercase 체계 재사용.
5. 구현 전 Mobbin/Nicelydone에서 SciSpace·Dropbox Dash·Gamma 실제 스크린 대조(src_041, src_042).
