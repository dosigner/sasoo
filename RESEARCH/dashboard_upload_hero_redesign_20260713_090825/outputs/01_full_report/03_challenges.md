# 3. 패턴 분석 — 무엇이 반복되고, 무엇을 피해야 하나

## 3.1 사례를 관통하는 3대 배치 패턴

**패턴 1 — 시작 진입점 상단 고정 + 최근 항목 상시 병존 (Dropbox Dash / Elicit / Gamma / Humata형)**
Elicit, Dropbox Dash, Gamma는 신규 시작 진입점을 상단에 고정하고 최근 항목을 같은 화면에 상시 병존시킨다(src_015, src_018, src_013). Humata도 신규 업로드와 기존 문서 리스트를 한 화면에 공존시킨다(src_011, src_012). 신규 사용자에게는 액션이, 재방문자에게는 이력이 동시에 보여 화면이 비어 보이지도, 복잡해 보이지도 않는다. **재방문·누적 라이브러리가 핵심 가치인 논문사수에 1순위 골격.**

**패턴 2 — 스탯은 Stripe 문법, 위치는 후순위 (Stripe / Linear / shadcn형)**
Stripe 홈은 짧은 라벨+큰 숫자+증감+스파크라인 카드 행(src_004, src_005), 대시보드 키트 표준도 스탯 카드 행 → 차트 → 테이블 스택(src_021, src_022, src_023, src_024). 단 Linear처럼 "액션 우선, 분석 후순위"(src_001) — 통계가 업로드보다 시각적으로 커지면 안 된다.

**패턴 3 — 업로드 직후 경험까지가 히어로 (SciSpace / Adobe / Humata형)**
SciSpace와 Adobe Acrobat AI는 업로드 직후 자동 요약과 추천 질문을 제시하고(src_010, src_020), Humata는 처리 상태를 펄싱과 카운트다운으로 시각화한다(src_011, src_012). 드롭존 디자인만이 아니라 "드롭 후 3초"의 연출이 요즘 업로드 히어로의 실체다.

## 3.2 시각 기조 (2026 기준선)

- 2026년 대시보드 비주얼 기조는 틴트된 뉴트럴 베이스에 단일 액센트, 보더·디바이더 축소와 배경 레이어·여백 기반 위계다(src_037, src_047, src_040).
- 색은 의미 전용으로 예약: 상태(성공/경고/오류)와 단일 CTA 액센트만. Ramp의 옐로우그린 단일 포인트(src_008)가 모범.
- 숫자는 tabular-nums, 마이크로 라벨은 대문자/자간 확대 절제 사용 — 현재 논문사수의 `text-2xs uppercase tracking` 라벨 관행과 이미 일치한다.

## 3.3 안티패턴 — 이번 조사에서 확인된 "하지 말 것"

1. **벤토 남용**: 벤토 그리드는 마케팅 페이지와 개요 화면에 적합하고, 작업 흐름 영역에 강제하는 것은 부적합하다는 실무 가이드가 있다(src_038, src_052, src_053). 논문 리스트·분석 결과는 일반 리스트/테이블 유지. 히어로+스탯 타일 2~4개까지만 벤토 문법.
2. **4칸 강박**: shadcn dashboard-01의 4카드는 예시일 뿐. 지표가 2개면 2칸 — 없는 지표를 만들어 채우지 말 것(src_021).
3. **일별 바차트 함정**: 간헐 사용 제품에서 일별 바는 대부분 0 — Anthropic/OpenAI식 일별 차트(src_025, src_026)는 트래픽이 매일 있는 서비스용. 논문사수는 월 누적 숫자 중심.
4. **PDF 썸네일 그리드**: 시각물 제품(Gamma·Figma)의 관례(src_014, src_030)를 논문에 이식하면 회색 종이 그리드가 된다. 행 리스트 유지.
5. **화려한 온보딩 체크리스트**: 목적을 갖고 들어오는 도구형 제품은 업로드 CTA를 키우는 게 우선(src_043).
6. **장식성 마이크로 인터랙션 축적**: 모션은 상태 변화를 확정해주는 최소 신호로 — 스태거 40~80ms/700ms 이내, 인터랙션 150~250ms 상한(src_050, src_051).
