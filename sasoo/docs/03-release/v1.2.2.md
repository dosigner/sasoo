# Sasoo v1.2.2

v1.2.1 이후 발견된 시각화 비용 기록 누락과 월별 집계를 고친 수정 릴리스입니다.

## 변경 내용

- Mermaid 응답에 텍스트가 없거나 생성한 이미지의 파일 저장이 실패해도 이미 실행한 유료 요청의 기록을 보존합니다. 이미지 저장 실패 때문에 다른 공급사에 다시 요청하지 않습니다.
- 이전 방식의 단일 Mermaid 생성과 수정 요청도 비용 원장에 기록합니다. 수정 대상 항목이 사라진 경우에도 이미 발생한 요청을 기록하며, 사용량을 확인하지 못한 요청은 비용 미확인 상태로 남깁니다.
- 나중에 다시 생성한 시각화의 비용은 실제 요청한 달(UTC 기준)에 집계됩니다. 비용 대시보드와 월 예산 한도가 같은 기준을 사용합니다.
- 월별 비용 API에 모델별 미확인 요청 수(`by_model_unknown`)를 추가했습니다. 이 필드를 별도로 표시하는 UI는 추가하지 않았습니다.

## 기존 데이터와 비용

DB 구조와 기존 논문 결과는 유지됩니다. 요청 시각이 없는 기존 기록은 처음 저장한 달로 집계하며, 과거에 누락된 요청의 비용을 복원하지는 않습니다. 토큰 수와 논문 수 역시 기존처럼 결과 행이 저장된 달을 따릅니다.

설정 화면의 비용은 보고된 사용량과 앱에 등록된 단가로 계산한 추정치이므로 공급사 청구액과 다를 수 있습니다. 비용 미확인 요청은 무료라는 뜻이 아닙니다.

## 설치 안내

macOS Apple Silicon과 Windows x64를 지원합니다. macOS 앱은 미서명, 미공증이며 Windows 설치 파일은 미서명이라 SmartScreen 경고가 나타날 수 있습니다. 공식 GitHub Releases에서 받은 파일만 사용하세요.

- macOS: ZIP을 풀거나 DMG를 열어 `Sasoo.app`을 `/Applications`로 옮깁니다.
- Windows: 설치 EXE를 실행합니다. 공식 파일인지 확인한 뒤 SmartScreen에서 `추가 정보` → `실행`을 선택할 수 있습니다.

macOS에서 공식 파일을 `/Applications`로 옮긴 후 실행이 차단될 때만 다음 명령을 사용하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Sasoo.app
```

이 명령은 quarantine 보호를 제거하며 Apple 서명이나 공증을 대신하지 않습니다. 제삼자에게 받은 파일에는 사용하지 마세요.

API 키는 운영체제 자격 증명 저장소에 보관됩니다. v0.6.x 이하에서 저장한 키는 이전 암호화 키가 남아 있으면 자동으로 이전됩니다. 이전할 수 없거나 공급사에서 폐기한 키는 설정에서 새로 입력하세요.
