# Sasoo v1.0.2 릴리스 노트 초안

## 사용자 변경

- 논문 목록 조회 실패와 빈 보관함을 구분하고, 홈/보관함/워크벤치에 재시도를 제공한다.
- 설정과 프로필의 현재값을 불러오지 못하면 편집을 차단한다. 저장하지 않은 값이 있으면 내부 페이지 이동 전에 확인한다.
- 확인창의 이름과 키보드 포커스 복귀, 라디오 방향키 조작, 긴 제목/파일명 처리, 밝은 테마의 보조 텍스트 대비를 개선한다.
- 질문 패널의 브랜드 오브와 키보드 열기/닫기 동작을 개선한다.
- 실험 단계 번호가 화면, CSV, Markdown에서 중복되지 않도록 맞춘다. 소수와 절 번호는 유지한다.
- v1.0.1 이후 main에 반영된 GPT-6 Luna와 Nano Banana 2.1 모델 목록, 그림 설명 스트리밍/요청 캐시, 한국어 강조와 분석 단계 표시 개선을 포함한다.
- Electron, sharp 및 간접 의존성의 보고된 취약점을 해결하고 잠금 파일을 갱신한다.

## 호환성과 확인 범위

분석 결과의 과학적 정확성이 새로 검증됐다는 뜻은 아니다. 이번 릴리스 준비에서 유료 분석/이미지 생성은 실행하지 않는다. 미저장 이동 확인은 내부 페이지 탐색에 적용되며 앱 종료/새로고침의 초안 보존은 포함하지 않는다.

## 배포 절차

1. PR #110의 최종 커밋에 대해 Windows Build Check와 로컬 macOS 후보 검증을 확인한다.
2. PR을 main에 병합하고, 원격 main이 승인된 소스 및 1.0.2 버전을 포함하는지 확인한다.
3. 병합된 정확한 main 커밋에 `v1.0.2` 태그를 만들고 push한다.
4. Release 워크플로의 macOS/Windows 산출물과 업데이트 manifest를 검증한다. 워크플로는 GitHub draft release를 만든다.
5. 두 플랫폼의 설치/실행 검증과 노트를 검토한 뒤 공개한다.

release.yml은 태그와 버전, 태그와 빌드 커밋의 일치, 빌드 커밋의 main 포함 여부를 검사한다. 기존 릴리스나 draft가 있으면 중단하므로, 태그 실행 전에 빈 draft를 미리 만들지 않는다.

## 설치 안내

macOS ZIP을 풀어 Sasoo.app을 Applications로 옮긴다. 현재 배포 절차는 미서명/미공증 앱을 전제로 하며, 공식 GitHub에서 받은 사본만 사용한다. Gatekeeper가 막으면 시스템의 열기 확인을 사용한다. 기존 문서의 quarantine 제거 명령은 발행자를 검증하는 기능이 아니다.

Windows 서명 인증서가 없으면 미서명 설치 파일을 만들며 SmartScreen 확인이 나타날 수 있다. 최종 산출물의 서명 상태는 Release 실행 결과로 확인한다.
