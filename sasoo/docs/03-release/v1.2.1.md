# Sasoo v1.2.1

v1.2.0의 혼합 시각화에서 발견된 문제를 고친 수정 릴리스입니다. 새 기능은 없습니다.

## 변경 내용

- ZIP으로 내보낸 HTML 설명이 다른 페이지로 이동하거나 외부로 요청을 보내지 못합니다.
- 다시 생성한 시각화는 생성을 시작한 분석 결과에만 저장됩니다. 그사이 재분석이 끝났다면 새 결과를 덮어쓰지 않고 안내를 표시합니다. 분석이 진행되는 동안 다시 생성한 결과도 유지됩니다.
- 생성 계획이 실패하거나 형식이 맞지 않으면 이미지 생성을 시작하지 않습니다. 저장된 계획에도 생성 직전에 배분 한도(이미지 5개, Mermaid 3개, HTML 1개, Sunburst 1개)를 다시 적용합니다.
- 재분석할 때 실패했거나 파일이 없는 항목만 다시 생성합니다. 이미 성공한 항목에는 비용을 다시 쓰지 않습니다.
- HTML 설명을 열면 실행을 점검해 스크립트 오류, assert 실패, NaN, 입력에 반응하지 않는 출력, 10초 안에 끝나지 않는 실행을 표시합니다. 이 점검은 수치를 원문과 대조하지 않으며, 화면에도 그렇게 표시합니다.
- 비용에 이미지 설명, Mermaid, 실패한 시도, 다시 생성과 수정 요청을 포함합니다. 사용량을 확인하지 못한 요청은 0원으로 더하지 않고 비용 화면과 홈에 "미확인 n건"으로 표시합니다.
- 확대 보기에서 키보드로 HTML 설명 안에 들어갈 수 있습니다.

## 적용과 비용

기존 논문 결과는 유지되며 DB 구조는 바뀌지 않습니다. v1.2.0에서 실패로 남은 항목은 재분석하거나 다시 생성하면 복구됩니다. v1.2.0에서 저장된 비용 기록에 빠져 있던 요청은 다시 계산되지 않습니다.

설정 화면의 비용은 보고된 사용량과 앱에 등록된 단가로 계산한 추정치입니다. 외부 API 비용은 별도이며, 공급사 청구액은 실제 사용량과 계정 조건에 따라 달라집니다. 다시 생성이 예상하지 못한 오류로 중단되면 그 요청의 비용이 기록되지 않을 수 있습니다.

## 설치 안내

macOS Apple Silicon과 Windows x64를 지원합니다. macOS 앱은 미서명, 미공증이며 Windows 설치 파일은 미서명이라 SmartScreen 경고가 나타날 수 있습니다.

macOS에서 공식 GitHub Releases로 받은 앱을 `/Applications`로 옮긴 후 Gatekeeper가 차단할 때만 다음 명령을 사용하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Sasoo.app
```

이 명령은 quarantine 보호를 제거하며 Apple 서명이나 공증을 대신하지 않습니다.
