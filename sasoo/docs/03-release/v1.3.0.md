# Sasoo v1.3.0

논문 읽기와 선택 문맥 채팅, 분석 완료 검사 및 시각화 원문 처리의 누적 변경을 포함한 minor 릴리스입니다. 보고서 조립 분리(R1)와 시각화 선택 규칙 분리(R3)도 포함합니다.

## 읽기와 채팅

- 읽기 가이드와 용어 사전을 함께 사용합니다. 용어 검색, 문맥 설명과 선택 비교를 지원하며, 용어를 가리키는 것만으로 공급사 요청을 보내지 않습니다.
- PDF에서 선택한 문장과 시작/끝 페이지를 채팅에 전달합니다. 분석 전에도 원문 텍스트가 준비되면 제한된 읽기 문맥으로 질문할 수 있습니다.
- 논문 전환 시 채팅 선택과 읽기 상태를 정리하고, 텍스트 준비 중인 화면의 상태를 갱신합니다.
- 논문의 학문 분야 표시와 분석 에이전트 배정을 구분합니다. 저장된 에이전트를 일괄 재분류하지 않습니다.

## 분석과 시각화

- 독립적으로 실행 가능한 분석 작업을 병렬로 조율하며, 취소와 부분 결과를 처리합니다. 속도 향상률을 보증하는 릴리스는 아닙니다.
- 단계별 필수 출력과 schema를 검사하고, 계획한 시각화와 실제 저장된 항목이 일치하는지 확인합니다. 실패하거나 불완전한 결과가 완료로 보이지 않도록 상태와 보고서를 보강했습니다.
- 기존 부분 결과를 읽을 수 있도록 유지하고, 확인하지 못한 비용을 0으로 바꾸지 않습니다. 시각화 사용량 기록의 중복 처리도 보강했습니다.
- 표와 식에 필요한 원문 문맥과 PDF 제공 정보를 시각화 요청에 전달합니다. 식의 역할이 뒤바뀐 이미지 설명과 미완성 HTML 응답을 검사합니다.
- 보고서 조립을 `report_service.py`, 시각화 선택 규칙을 `visualization_policy.py`로 분리했습니다. 관련 리팩토링에서는 기존 보고서 바이트와 선택 규칙을 유지했습니다.

## 기존 데이터와 비용

기존 논문, 결과와 유료 산출물을 자동 삭제하거나 일괄 재생성하지 않습니다. 새 완료 기준이 없던 과거 결과는 읽을 수 있어도 부분 또는 오류 상태로 표시될 수 있습니다. 이는 해당 논문의 과학적 내용이 틀렸다고 판정한 것이 아닙니다.

시각화 캐시 조건에는 원문과 PDF 식별 정보가 추가됐습니다. 사용자가 재분석 또는 재생성을 요청하면 일부 과거 캐시가 재사용되지 않아 새 유료 요청이 발생할 수 있습니다. 공급사 사용량을 확인하지 못한 요청은 비용 미확인으로 남으며 무료를 뜻하지 않습니다.

완료 표시는 필수 산출물과 저장 형식을 확인한 상태입니다. 실제 도구 실행, 원문 근거, 과학적 정확성과 공급사 청구는 별도 검증이 필요합니다. 실행 manifest와 요청별 비용 원장 전체, 레거시 상태 표시 개선 등 후속 계획이 모두 완료된 것은 아닙니다.

## 배포 호환성

릴리스 검사에서 확인된 취약 패키지를 갱신하고 하위 의존성의 수정 버전을 지정했습니다. PDF 인용 위치 검색의 기존 계약을 유지하기 위해 PyMuPDF는 검증한 1.x 범위로 제한합니다. PyMuPDF 2.x에서는 같은 줄바꿈 하이픈 검색이 다른 결과를 내므로 이번 릴리스의 지원 범위에서 제외했습니다.

## 설치 안내

macOS Apple Silicon과 Windows x64를 지원합니다. macOS 앱은 미서명, 미공증이며 Windows 설치 파일은 미서명이라 SmartScreen 경고가 나타날 수 있습니다. 공식 GitHub Releases에서 받은 파일만 사용하세요.

- macOS: ZIP을 풀거나 DMG를 열어 `Sasoo.app`을 `/Applications`로 옮깁니다.
- Windows: 설치 EXE를 실행합니다. 공식 파일인지 확인한 뒤 SmartScreen에서 `추가 정보` → `실행`을 선택할 수 있습니다.

macOS에서 공식 파일을 `/Applications`로 옮긴 후 실행이 차단될 때만 다음 명령을 사용하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Sasoo.app
```

이 명령은 quarantine 보호를 제거하며 발행자를 검증하거나 Apple 서명과 공증을 대신하지 않습니다. 제삼자에게 받은 파일에는 사용하지 마세요.

API 키는 운영체제 자격 증명 저장소에 보관됩니다. v0.6.x 이하에서 저장한 키는 이전 암호화 키가 남아 있으면 자동으로 이전됩니다. 이전할 수 없거나 공급사에서 폐기한 키는 설정에서 새로 입력하세요.
