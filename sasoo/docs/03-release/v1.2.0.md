# Sasoo v1.2.0

## 변경 내용

- 구조, 과정과 상태 변화, 기존 방식과 제안 방식 비교는 이미지로 설명합니다. 역할과 시간 순서는 Mermaid sequence, 변수와 출력의 관계는 HTML 설명으로 생성합니다. 논문 근거가 없는 유형은 건너뜁니다.
- 기본 이미지는 `gpt-image-2.5-flare`를 사용합니다. 중요도 60점 이상, 난이도 70점 이상인 핵심 이미지 중 가장 어려운 하나만 `gpt-image-2.5-sunburst`를 사용합니다. 추가 이미지에는 Sunburst를 사용하지 않습니다.
- 중요도 60점 이상의 추가 이미지와 Mermaid 도식을 각각 최대 2개 허용합니다. 중요도와 난이도는 생성 계획의 판단 점수이며 확률이 아닙니다.
- 설정의 이미지 품질 한도를 유지합니다. 높은 품질이 허용되면 과정과 비교는 high, 구조와 추가 이미지는 medium을 사용합니다.
- 카드에 모델, 품질, 중요도와 난이도를 표시하고 모델과 품질을 캐시와 파일 이름에 반영합니다. 사용량을 확인하지 못한 비용은 0원으로 처리하지 않습니다.
- HTML 설명은 sandbox와 CSP로 앱, 저장소와 외부 네트워크 접근을 차단합니다. 계산 오류를 표시하고 ZIP 내보내기에 HTML을 포함합니다.

## 적용과 비용

기존 논문 결과는 유지됩니다. 새 생성 배분은 재분석할 때 적용됩니다. 혼합 시각화의 이미지 생성은 분석 공급사와 관계없이 OpenAI API 키를 사용합니다. 외부 API 비용은 별도이며, 공급사 청구액은 실제 사용량과 계정 조건에 따라 달라집니다.

시각화의 과학적 정확성을 모든 논문에서 검증한 것은 아닙니다. 이미지와 HTML의 가정, 단위와 원문 근거를 함께 확인하세요.

## 설치 안내

macOS Apple Silicon과 Windows x64를 지원합니다. macOS 앱은 미서명, 미공증이며 Windows 설치 파일은 미서명이라 SmartScreen 경고가 나타날 수 있습니다.

macOS에서 공식 GitHub Releases로 받은 앱을 `/Applications`로 옮긴 후 Gatekeeper가 차단할 때만 다음 명령을 사용하세요.

```bash
xattr -dr com.apple.quarantine /Applications/Sasoo.app
```

이 명령은 quarantine 보호를 제거하며 Apple 서명이나 공증을 대신하지 않습니다. 저장된 API 키는 가능한 경우 자동으로 이전되며, 이전하지 못하거나 공급사에서 폐기된 키는 다시 입력해야 합니다.
